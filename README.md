## Run Locally

Open the project folder and run:

```cmd
cd /d "d:\portfolio website"
py -m http.server 5500
```

Then open:

```text
http://127.0.0.1:5500/
```

You can also open `index.html` directly in the browser.

---

## Deployment

This website is deployed using **GitHub Pages** with **GitHub Actions**.

Whenever changes are pushed to the `main` branch, the site is automatically redeployed.
